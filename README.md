# gr-waste

A tiny, address-in / schedule-out lookup for Grand Rapids, MI trash, recycling, and yard waste pickup days.

Pulls directly from the City of Grand Rapids' public GIS route layers (Refuse_Route_New, GR_Recycle_Routes, YardWaste_Routes) instead of requiring you to click through an interactive map and cross-reference a PDF calendar.

No build step, no dependencies — a single static `index.html`.

Styled with the [Finch](https://github.com/finch-build) monochrome ink-on-paper identity system, including a `prefers-color-scheme: dark` reversed variant.
